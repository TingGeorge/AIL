# 07: 位置授權與距離估算

**What to build:** 讓距離與時間限制真的能篩掉東西。使用者按下搜尋時，瀏覽器在取得同意後取一次目前位置，隨這次請求送出，用完就丟 — 不寫進資料庫、不寫進 log。伺服器對有座標的紀錄算直線距離，並以固定步行速度換算成分鐘，兩者在畫面上都必須標示「估算」。

沒有取得位置（拒絕、逾時、瀏覽器不支援）時，距離篩選整個停用，畫面說明為什麼距離條件這次沒有生效；個別紀錄沒有座標時，該筆顯示但不做距離篩選，不會因為算不出距離就被丟掉。

**Blocked by:** 05, 04

**Status:** ready-for-agent

- [ ] 只有在使用者同意後才取得位置，且僅用於該次搜尋；沒有任何保存或 log 的路徑
- [ ] `max_distance_km` 與 `max_minutes` 會排除超出範圍的紀錄，並計入該限制的 excluded_by
- [ ] 距離與換算後的時間在卡片與詳情頁一律標「估算」；來源自己寫的距離文字原樣顯示、不與估算值混用
- [ ] 使用者拒絕授權或取不到位置時，距離篩選停用、其他限制照常，畫面明說距離條件未生效
- [ ] 沒有座標的紀錄仍出現在結果中，只是不參與距離篩選
- [ ] 經緯度沒有寫反：以已知的兩個座標驗證距離量級合理（同區內為個位數公里）
