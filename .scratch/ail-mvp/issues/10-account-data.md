# 10: 帳號資料：清單、收藏與設定

**What to build:** 讓登入的使用者把清單、收藏與設定存到帳號，換一台裝置登入還在。整包讀、整包寫，每個帳號一列一份清單。

匿名使用者可以改設定（只留在該分頁），但點 ★ 或加入清單時提示登入且不寫入任何資料 — 不做匿名資料合併，登入後帳號資料直接取代這個分頁的設定，語音、逐字稿與需求限制不遷移。

同時接上兩個依賴設定的既有行為：清單頁按「標記已買」把該筆移出清單並把總可比成本累加到已花費（加入清單不累加，加入清單不等於花錢），跨月時已花費歸零；Costco 會員開關關閉時，需要會員的候選不進排序、以會員價當基準的節省也不計算。

**Blocked by:** 08, 11

**Status:** ready-for-agent

- [ ] 讀寫帳號資料的路由需要登入；回傳與寫入的是清單、收藏、設定與個人化四個部分的整包內容
- [ ] 登入後清單與收藏從帳號資料還原；重新整理仍在
- [ ] 匿名點 ★ 或加入清單時提示登入，且確認沒有任何寫入發生
- [ ] 登入後帳號資料取代目前分頁的設定，不做合併
- [ ] 「標記已買」把該筆移出清單並累加已花費；加入清單不影響已花費
- [ ] 已花費的月份與當月不同時歸零並更新月份
- [ ] Costco 會員開關關閉時，需要會員資格的候選不出現在推薦排序，且不以會員價計算節省
