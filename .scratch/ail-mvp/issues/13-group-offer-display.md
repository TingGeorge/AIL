# 13: 揪團改為純顯示

**What to build:** 揪團不再追蹤成員。使用者打開一筆有團體優惠的紀錄時，看到的是商家的兌換碼、人數條件、以及成本試算（自己一個人的總可比成本／達到人數條件後的總額／每人分攤），加上一個分享按鈕。兌換碼由商家到店驗證，平台不記誰參加、不產生加入代碼、不建任何資料表。

順手清掉因此變成孤兒的東西：成員列表、加入代碼產生器、以及示範用的假成員資料。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 揪團畫面顯示兌換碼、最低人數與條件說明
- [ ] 成本試算三個數字（單獨／成團後／每人）與紀錄上的團體優惠欄位一致；優惠是百分比或每人固定價兩種形式都算得對
- [ ] 分享按鈕可用
- [ ] 沒有團體優惠的紀錄不顯示揪團入口
- [ ] 成員列表、加入代碼與相關型別、假成員資料都已移除，沒有殘留的呼叫端
