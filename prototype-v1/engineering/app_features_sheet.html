開啟 PRD
最短版本 這是一個固定在圓山區、匿名可用、可選帳號、語音優先的生活選項搜尋 Web App：使用者說出需求， 系統解析限制，確認後查看有來源與證據的食品、日用品、免費資源、活動與交通選項。目前語音 API 與 UI 有基礎實作，但真實搜尋、Auth code、Database 與交易流程尚未接上。

共享狀態與長期資料

Account、auth sessions、帳號資料（清單、收藏、設定）、真實使用者回報，以及事先匯入的候選紀錄、來源、證據與驗證狀態。揪團改為純顯示，不需要 DB。

看產品選擇可選：快取／持久化

快取、資料集與跨裝置

搜尋快取、baseline、跨裝置收藏／清單、設定、分享連結與長期帳號資料可使用 DB；MVP 已定義 Auth logical schema，但實作尚未接上。

刻意不包含的功能

交易與即時服務

不包含付款、下單、票券核銷、即時庫存、即時名額、營業狀態保證或即時交通到站。

地圖與健康判斷

不包含導航、地圖、路線規劃、turn-by-turn、健康／營養／醫療建議。

進階對話與語音

不包含 TTS、即時逐字稿串流、靜音自動停止、長按錄音、語言切換、卡片語音指令或多輪追問。

帳號與長期資料

不包含跨裝置需求歷史、完整個人檔案、精確位置保存與交易；可選帳號已列入 MVP，但 Auth 與 Database 尚未實作。

目前最重要的落差 UI 已經把「搜尋完成後」的體驗畫出來，但 production path 還缺真實搜尋 API、Agent orchestration、 候選資料 pipeline、Auth implementation 與 Database implementation。非 preview 模式進入搜尋時，兩個 Agent 目前會顯示尚未接上。
